# Dataset-Kasasi-Perdata-Kasus-Perbuatan-Melawan-Hukum-Tahun-2023-2024
Dataset putusan kasasi perdata kasus Perbuatan Melawan Hukum (PMH) pada tahun 2023–2024. Dataset disusun untuk mendukung kebutuhan penelitian, analisis hukum, pengolahan data, serta pengembangan sistem berbasis teknologi hukum (legal technology).
